# Reusable AI Work OS

Before implementation, read `docs/ai/WORKFLOW.md` and `docs/ai/project.yaml`.

Use this stage order:

1. User interview
2. Claude plan
3. Antigravity implementation
4. Antigravity first verification
5. GitHub Handoff
6. GPT second verification
7. Learning and reverse design

Every task must have observable acceptance checks, a Handoff file, and verification evidence. Do not claim completion from code inspection alone. Never commit secrets or merge production changes without explicit user approval.
