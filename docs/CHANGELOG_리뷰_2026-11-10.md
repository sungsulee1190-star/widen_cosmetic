| 방문 기록 HTML 이스케이프 | 매장명·메모에 `<img src=x onerror=...>` 를 넣으면 그대로 실행됐음. 지금은 본인 입력이라 위험이 작지만, 기획대로 구글 시트·크롤링 데이터를 붙이면 외부 문자열이 들어오게 됨 | `esc()` 로 이스케이프. 실제로 위 문자열을 넣어 실행되지 않고 글자로 표시되는 것 확인 |

| 데이터 로딩 실패 안내 | `index.html` 을 더블클릭으로 열면(예전 walkthrough 문서가 그렇게 안내했음) JSON 을 못 읽어서 **모든 화면이 "데이터 없음"인데 이유를 알 수 없었음** | 실패를 기록하고 화면 상단에 빨간 배너로 표시. `file://` 이면 `python3 -m http.server` 실행 방법까지 안내 |
| 화면 단위 오류 격리 | 한 화면에서 오류가 나면 아무것도 안 보였음 (1번 버그처럼) | 라우터에서 try/catch → 그 화면에만 오류 메시지 표시, 다른 메뉴는 정상 |
| 마지막 화면 복원 | 메뉴 ID 가 바뀌면 저장된 ID 로 이동하다 빈 화면 | 없는 ID 면 '이번주 할일' 로 |

## ⏭️ 이번에 손대지 않은 것 (피터 확인 필요)

1. **데이터가 7월 기준에 멈춰 있음.** 시즌 캘린더는 "7월", 주차는 W27~29, 오프라인 확인일은 7월 초입니다. 지금은 11월이라 첫 화면의 "지금 뜨는 카테고리 = 선크림" 은 시기상 맞지 않습니다. 데이터 갱신은 판단이 필요해서 그대로 뒀습니다.
2. **'경쟁페이지 분석' 실제 데이터화.** 지금은 샘플 표시만 했습니다. 실제 경쟁사/인플루언서를 `data/references.json` 으로 빼는 것을 추천합니다.
3. **LocalStorage 한계.** 체크·방문 기록이 브라우저 한 곳에만 저장됩니다. 여러 명이 쓰거나 PC 를 바꾸면 사라집니다. 기획서의 Notion / 구글 시트 연동이 실제 해법입니다. 당장은 "방문 기록 CSV 내보내기" 정도를 붙일 수 있습니다.
4. **이스케이프 범위.** 사용자 입력(방문 기록)과 링크·업로드·시즌 화면은 이스케이프했지만, 나머지 화면은 `data/*.json` 을 신뢰하고 그대로 그립니다. 외부 시트 연동을 붙일 때는 전 화면에 `esc()` 를 적용해야 합니다.
5. **국가별 체크리스트 체크 상태가 저장되지 않음.** 새로고침하면 풀립니다. 의도(매번 새로 점검)인지 확인 필요.
6. **Shopee TW.** 필터 옵션은 있지만 데이터에 Shopee 링크·가격이 하나도 없어서 항상 0개입니다.
7. **이미지 핫링크.** 제품 이미지를 올리브영 CDN 에서 직접 불러옵니다. 올리브영이 막으면 이미지가 전부 깨집니다. Drive 에 저장해서 쓰는 게 안전합니다.
