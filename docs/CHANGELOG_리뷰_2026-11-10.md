### 🔎 검색 규칙 통일 (`matchesQuery()` — 모든 검색창 공통)

**왜:** 예전 검색은 입력한 글자 전체를 한 덩어리로 찾았습니다. 그래서 `VT 세럼`처럼 두 단어를 치면 "VT 세럼" 이라는 연속 문자열이 없어서 **아무것도 안 나왔고**, `리들샷100`처럼 띄어쓰기만 달라도 못 찾았습니다. 화면마다 검색 대상 필드도 제각각이었습니다.

**어떻게:** 규칙을 하나로 정하고 `js/utils.js` 에 모았습니다.

| 규칙 | 예시 (실측) |
|---|---|
| 대소문자 무시 + 전각/반각 통일 | `pdrn` = `PDRN` = `ＰＤＲＮ` |
| 띄어쓰기로 나눈 단어가 **모두** 포함 (AND) | `VT PDRN` → 1개 (VT 리들샷) / `VT 레티놀` → 0개 |
| 띄어쓰기 차이 무시 | `리들샷100` → VT 리들샷 100 |
| 빈 검색어 = 전체 | |

| 화면 | 검색 대상 (예전 → 지금) |
|---|---|
| 📦 카테고리/제품 | 제품명·브랜드 → + 성분·카테고리·대분류·상태·소싱처 |
| 🧪 성분/트렌드 | 성분명·정식명 → + 설명·트렌드 이유·타겟·대표 SKU·**안전/위험 표현**. 표현으로 검색하면(예: `미백`) 해당 칩에 테두리가 생겨 "이 표현 써도 되나?"를 바로 확인 |
| 🌏 국가별 규제 | 검색 없음 → **검색창 추가**. 일치하는 규제 항목만 남기고, 해당 없는 섹션은 접고, 나라 카드에 "관련 항목 없음" 표시 (예: `레티놀` → 65개 항목 중 2개) |

모든 검색에 **결과 개수**(`10개 중 2개 표시`)와 **0건일 때 안내 문구**를 붙였습니다. 0건이면 어떤 조건 때문인지(`검색 "zzz" + 즐겨찾기`)까지 보여줍니다.
