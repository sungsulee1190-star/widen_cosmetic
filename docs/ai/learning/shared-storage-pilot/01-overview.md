# 01. 개요

이 파일럿의 목적은 브라우저의 `localStorage`를 작업 원본으로 쓰던 구조를 Supabase 기반 공유 저장소로 옮기는 것이다.

핵심 원칙:

- Git에는 정적 데이터와 코드만 둔다.
- 사용자가 바꾸는 상태는 사용자 계정 소유 행으로 저장한다.
- 로그인하지 않았거나 원격 저장소가 실패하면 로컬 fallback을 사용하되 상태를 화면에 표시한다.
- 비밀 키는 브라우저에 넣지 않는다. 프론트엔드에는 공개 publishable key만 둔다.

이번 파일럿은 기존 네 개의 상태 키와 후보 상품 키를 대상으로 한다. 메모, 루틴, 링크를 개별 레코드로 분리하는 작업은 다음 단계다.
