## 0. 남성복과 다른 점 — 화장품은 "쓸 수 있는 말"이 법으로 정해져 있음

일본 약기법(薬機法)상 **일반 화장품이 광고할 수 있는 효능은 56개뿐**입니다 (후생노동성 통지 「化粧品の効能の範囲」, 平成12年·平成23年 개정 — 출처: [오사카부 게재본](https://www.pref.osaka.lg.jp/yakumu/shinsa/hyou1-4.html)).
그래서 이 공식에서 **카피는 "56개 안에서 고른다"가 먼저**이고, 예쁜 문장은 그다음입니다.

### 절대 쓰지 않는 말 (대시보드 `국가별 규제` · `성분/트렌드` 와 같은 기준)
- 미백(美白)·주름 개선 → **의약부외품만** 가능
- 治る/治療/改善/再生/細胞 → 의약품적 표현
- "시술급", "피부과 효과", "MTS 대체", "DNA 재생" → 대시보드 성분 위키의 **위험 표현**
- "No.1", "1위" → 출처(랭킹명·기간)를 바로 옆에 적을 수 있을 때만. 예: `Qoo10 2026年9月 月間ランキング リップクリーム・バーム部門 1位`
- 효과를 보장하는 말(必ず/絶対/100%), 비포·애프터 사진

### 성분을 강조할 때의 형식
성분 이름을 크게 쓰면 **무슨 목적으로 넣었는지** 괄호로 붙입니다. 예: `ヒアルロン酸Na（保湿成分）`, `PDRN（整肌成分）`.
(일본 화장품 업계 광고 가이드라인의 관행. 성분 = 효능으로 읽히지 않게 하기 위함 — 등록 전 원문 확인)

## 2. 카피 규칙

- **일본어 본문 + 한국어 검토본**을 같이 만든다. 판매 페이지에는 일본어만 올라간다.
- 일본어는 です·ます, 짧게. 한 문장에 효능 하나.
- 효능 문장은 위 56개 표에서 **골라 붙인다**. 새로 만들지 않는다.
- 숫자(가격·용량·랭킹·리뷰 수)는 출처가 있는 것만. 모르는 값은 `{ }` 로 비운다 (남성복 공식과 같은 규칙).
- 브랜드 공식 이미지·로고를 복제하지 않는다. 브랜드명은 상품명·성분 설명에 필요한 만큼만.

## 3. 사진 규칙
- 제품·텍스처·구성 사진은 **실물**. 시안에서는 회색 자리 + `실물 사진 필요` 라벨.
- 외부 이미지 핫링크 금지 (대시보드와 같은 이유: 올리브영 이미지가 403 으로 막힘). 사진은 `images/` 폴더.
- 비포·애프터 사진 금지.

## 4. 검수 체크리스트 (완성 후 반드시)
- [ ] 효능 문장이 전부 56개 표 안에 있음 (번호를 작업 메모에 적음)
- [ ] 대시보드 성분 위키의 **위험 표현**이 한 개도 없음
- [ ] 미백·주름 개선·치료·재생 표현 없음 (한국어 검토본 포함)
- [ ] 성분 강조에 `（배합 목적）` 표기
- [ ] "1위/No.1" 옆에 랭킹명·기간 표기, 없으면 삭제
- [ ] 全成分 일본어, 내용량, 제조국, 사용기한, 배송·관세 안내
- [ ] 가격·마진이 비어 있으면 `{ }` 로 남아 있음 (지어낸 숫자 없음)
- [ ] 재판매 가능 여부(브랜드 정책) 확인 결과를 작업 메모에 적음

## 6. 실제 페이지에서 본 것 (v2, 2026-11-12)

관찰 범위: Qoo10 売れ筋ランキング 総合 상위 30개 상품명, VT 公式ショップ 「【Qoo10限定販売】CICA 2X バランシングセラム 30ml」 상품 페이지 1개. (스크린샷은 저장하지 않음 — 다시 볼 땐 같은 페이지를 열 것)

### 6-1. 상품명(검색 노출) 문법 — ①에 추가
상위 상품명은 거의 같은 틀입니다:

`【태그】` + 제품명 + 용량 + `/` + 검색 키워드 나열

- 태그 예: `【Qoo10限定販売】` `【Qoo10 Only】` `【NEW】` `【GIFT付】` `【メガデビュー限定!】` `【2+1】`, 랭킹 근거가 있으면 `【化粧水1位】` 처럼
- 키워드 예: `韓国コスメ` `韓国スキンケア` `保湿` `敏感肌` 용량·매수
- **따라 하지 말 것**: 상위 상품명에도 `髪質改善` `トラブル跡ケア` `ニキビ超急速ケア` `ダメージ補修` 같은 56개 밖 표현이 보입니다. 일부는 일본에서 **의약부외품 승인을 받은 버전**이라 쓸 수 있는 것일 수 있고(예: 트라넥삼산 배합 제품), 우리가 한국에서 사입한 일반 화장품에는 쓸 수 없습니다. → 경쟁 페이지 문구를 그대로 가져오지 말고 56개 표로 다시 쓴다.

### 6-2. 첫 화면(상품 상단) — ①에 추가
- 신뢰 배지가 가격보다 위: `公式ショップ` `送料無料` `Qoo10 AWARDS 受賞ショップ`
- 가격: 정가 취소선 + 할인율(%) + 할인가, 그 아래 쿠폰(`+10%ショップカート割`)
- 평점·리뷰 수, 그리고 **AI 리뷰 요약**(Qoo10 자동)이 바로 아래
- → 우리 ①은 사진 + 훅 + 배지 3개로 충분하고, 가격·쿠폰은 Qoo10 상품 등록 화면에서 설정하는 영역(상세 이미지에 넣지 않음)

### 6-3. 상세 본문 = 이미지 — 전체에 적용
- 상세 본문은 텍스트가 아니라 **세로로 긴 이미지 수십 장**(관찰 페이지 약 46장)
- 맨 앞은 상품 설명이 아니라 **샵 전체 기획전 배너**(다른 상품 세트·특가, 기획전 예고 날짜)
- → 우리 HTML 시안은 "이미지로 뽑기 전 원고". 최종은 구간별로 860px 폭 이미지로 만든다. 샵에 상품이 여러 개가 되면 맨 앞에 **기획전 배너 1장** 구간(⓪)을 둔다.

### 6-4. 리뷰 — ⑧ 보강
- 상단 Best 리뷰 대부분이 `サンプルマーケットで当選` (Qoo10 **サンプルマーケット** = 체험단) 리뷰
- 리뷰에 사진·**텍스처 영상**이 붙고, 항목별 평가(`スペシャルケア` `満足感` `テクスチャー`)가 있음
- → 첫 리뷰는 サンプルマーケット 로 모은다(리뷰 0개 상태로 시작하지 않기). ④ 사용감 구간은 리뷰의 "텍스처" 평가와 같은 단어로 맞춘다.

### 6-5. 일정 힌트
- VT 公式 상세 배너: `Qoo10限定企画 … 11/20(金)10時 - 12/2(水)` "Coming Soon" — **Qoo10 공식 공지가 아니라 브랜드 배너**라서 메가와리 확정 일정으로 쓰지 않는다. 공식 공지 확인용 힌트.
